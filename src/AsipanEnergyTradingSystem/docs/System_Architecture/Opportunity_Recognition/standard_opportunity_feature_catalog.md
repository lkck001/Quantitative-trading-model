# 12 大标准交易机会特征目录（V0.1）

## 1. 文档目的

本文件把书中描述、标准结构图和案例经验转换为统一的算法特征语言。V0.1 只冻结特征名称和结构关系；所有尚未通过案例验证的数值阈值统一标记为 `TBD`。

## 2. 统一分类

| 结构家族 | 标准机会 | 共同识别核心 |
|---|---|---|
| 释放加积累 | 上矩、下矩、上三、下三、上旗、下旗 | 强释放、有限回撤、充分积累、边界几何、时间比例 |
| 趋势通道 | 上升通道、下降通道 | 高低点推进、平行边界、反复触及、延续时间 |
| 反转结构 | 头肩顶、头肩底、M 头、W 底 | 前置趋势、关键枢轴相对位置、颈线、形成与确认状态 |

上矩、上三、上旗中的“上”表示前置主要释放向上；“下”表示前置主要释放向下。突破方向和最终交易结果必须单独记录，不能从类型名称推断。

## 3. 跨标的泛化架构

### 3.1 三层分离

| 层级 | 学习内容 | 是否允许按品种调整 |
|---|---|---|
| 几何核心 | 枢轴顺序、相对高低、方向交替、比例、平行、收敛、对称、触及关系 | 不允许；跨标的冻结 |
| 校准适配层 | 枢轴最小显著度、波动率分位数、持续时间范围、突破缓冲和质量阈值 | 允许；按品种与周期校准 |
| 环境与交易层 | 关键位置、共振、流动性、交易时段、成本、目标位和风控 | 允许；不得反向改变几何类别 |

识别器必须同时输出 `geometry_score` 和 `calibrated_score`。前者用于评价形态本身，后者用于评价该形态在当前标的和周期上是否足够清晰。

### 3.2 规范化关键点集合

原始关键点为 `(time_i, price_i)`。对存在主要释放的形态，先将多空镜像统一，再转换为无量纲坐标：

```text
direction = sign(release_end_price - release_start_price)
x_i = (time_i - release_start_time) / max(ready_time - release_start_time, 1)
y_i = direction * (price_i - release_start_price) / max(abs(release_end_price - release_start_price), epsilon)
```

转换后应满足：

- 价格整体平移不改变结果。
- 价格按任意正比例缩放不改变结果。
- 相同结构在不同 K 线数量下时间拉伸后仍保持相近结果。
- 向下释放经过镜像后可与向上释放共享同一套几何逻辑。
- 绝对点数、价格位数和合约乘数不进入几何核心。

通道和无明确单一释放段的反转结构，纵轴使用局部稳健价格范围或 ATR 尺度，横轴使用结构总时长归一化。

### 3.3 图结构表示

每个机会表示为有序关键点图，而不是固定像素图片：

```text
nodes: P1, P2, ... Pn
node attributes: normalized_x, normalized_y, pivot_type, prominence
edges: 相邻关键点之间的时间差、价格差和方向
line groups: upper_boundary, lower_boundary, neckline
relations: above, below, near, parallel, converging, symmetric, touches
```

几何核心优先判断关系：

1. 关键点的时间顺序和高低交替。
2. 点与点之间的相对高低，而非绝对价格差。
3. 边线之间的平行、收敛或同向关系。
4. 回撤、宽度、时间和对称性的比例。
5. 最小必要结构何时首次成立。

### 3.4 泛化测试门禁

共同引擎必须包含以下变换测试：

| 测试 | 处理 | 期望结果 |
|---|---|---|
| 价格平移 | 所有价格加常数 | 类型与 `geometry_score` 基本不变 |
| 价格缩放 | 所有价格乘正数 | 类型与 `geometry_score` 基本不变 |
| 时间拉伸 | 相邻关键点时间同比放大 | 类型不变，时间质量评分可由适配层调整 |
| 多空镜像 | 价格围绕基准翻转 | 上下镜像类型互换，规范化几何相同 |
| 轻微噪声 | 在 ATR 小比例范围加入扰动 | 类型稳定，评分小幅变化 |
| 新标的留出 | 完全不参与规则调参的品种 | 不修改几何核心即可运行，只允许校准适配层 |

跨市场验证采用 `leave-one-symbol-out`：使用若干标的建立和校准结构规则，完整留出一个新标的做迁移测试。若必须修改关键点关系或几何规则才能适配新标的，说明几何核心发生了过拟合。

### 3.5 视觉感知与结构推理

人的视觉判断不是逐根计算 K 线，而是先压缩细节、发现显著转折、连接边界、识别整体轮廓，再容忍局部噪声完成分类。算法用以下双通道模拟这一过程：

```text
OHLC
  +-- 感知几何通道：多尺度 -> 显著枢轴 -> 线/区域 -> 关系图 -> 几何评分
  +-- 图像视觉通道：标准化渲染 -> 视觉嵌入/模板相似度 -> 视觉评分
                                                     |
                              geometry_score + visual_score + calibrated_score
                                                     |
                                             最终候选与解释
```

#### 感知几何通道（主通道）

| 人的视觉能力 | 算法对应能力 |
|---|---|
| 忽略细碎波动 | ATR/显著度控制的因果枢轴、分层 ZigZag、感知重要点 |
| 从不同缩放级别观察 | 同一时刻使用多个枢轴尺度和多个候选窗口 |
| 看出连续边线 | 稳健回归或 RANSAC 拟合，并允许少量刺破 |
| 识别整体轮廓 | 有序关键点图、边线组和区域宽度变化 |
| 判断大致平行、接近、对称 | 连续隶属度评分，不用单一硬阈值 |
| 区分形成中与已完成 | `FORMING -> READY -> CONFIRMED/INVALID` 状态演化 |
| 解释为什么像某种形态 | 输出 P1–Pn、边线、关系、通过项和失败项 |

主通道直接处理 OHLC 和已确认结构，不依赖截图颜色、坐标轴、窗口大小或交易软件界面。

#### 图像视觉通道（辅助通道）

图像通道不直接使用现有带文字、入场线和结果信息的案例截图训练。训练或匹配图像必须从 OHLC 统一生成：

- 固定画布比例、K 线宽度、边距和颜色。
- 只渲染到 `ready_time`，不得包含后续突破结果。
- 隐藏品种名、日期、价格刻度、订单、盈利文字和人工分类标签。
- 对配色、线宽、分辨率和轻微缩放做增强，避免模型记住界面样式。
- 输出 `visual_score`，仅用于候选重排或争议样本复核。

当前分类案例数量不足以从零训练稳定的视觉模型，因此实施顺序为：先完成感知几何通道，再利用自动扫描生成的大量候选窗口构建标准化图像数据集，最后评估迁移学习或视觉嵌入。

#### 模糊视觉关系

人的判断通常是“接近平行”“大致对称”“回撤较小”，因此每项关系输出 `[0, 1]` 连续分数：

```text
parallel_score
convergence_score
symmetry_score
touch_score
spacing_score
closure_score
```

硬性结构错误负责否决，视觉模糊关系负责评分。这样既保留标准边界，又避免单个噪声点导致整个形态从通过瞬间变为失败。

视觉能力验收增加以下不变性测试：修改标准化图的背景色、涨跌颜色、分辨率、K 线宽度和边距后，类型和评分应保持稳定；若结果明显变化，说明图像通道学习了界面而不是几何结构。

## 4. 统一时间与状态

| 字段 | 含义 | 因果要求 |
|---|---|---|
| `context_start` | 前置行情环境开始 | 只用于上下文分析 |
| `release_start` | 主要能量释放起点 | 必须由当时可见结构或已确认枢轴确定 |
| `release_end` | 主要释放结束、积累开始附近 | 不允许用后续完整图形反向移动 |
| `formation_start` | 结构形成起点，通常接近 P1 | 与释放结束可相同或相邻 |
| `ready_time` | 当时已具备最小标准结构、可以报出机会的时刻 | 核心识别时间；训练和回测不得使用其后的数据 |
| `breakout_time` | 价格有效越过边线或颈线的时间 | 可为空；属于确认或交易触发，不等于形成时刻 |
| `invalid_time` | 结构违反回撤、边线或枢轴关系的时间 | 一旦发生，形成态应转为失效态 |
| `pivot_time` | 高低点实际发生时间 | 仅用于绘图和结构归属 |
| `pivot_confirmed_at` | 高低点被右侧行情确认的时间 | 回测使用此时间，禁止提前使用 `pivot_time` |

统一状态机：

```text
SEARCHING -> FORMING -> READY -> CONFIRMED
                    \-> INVALID
```

## 5. 共同特征字典

### 5.1 尺度与释放

| 特征 | 建议定义 | 用途 |
|---|---|---|
| `atr_value` | `ATR(period)`，周期 `TBD` | 跨年份、品种和周期归一化 |
| `release_direction` | `sign(close_end - close_start)` | 区分上下释放 |
| `release_amplitude_atr` | `abs(price_end - price_start) / ATR` | 替代肉眼“幅度大” |
| `release_duration_bars` | 释放段 K 线数量 | 与积累时间比较 |
| `release_slope_norm` | `release_amplitude_atr / release_duration_bars` | 替代依赖缩放比例的 45°/90°图面角度 |
| `release_efficiency` | `abs(net_move) / sum(abs(bar_move))` | 衡量释放是否直接、是否反复回撤 |
| `directional_bar_ratio` | 顺释放方向 K 线数量占比 | 表达阳盛阴衰或阴盛阳衰 |
| `release_max_pullback_ratio` | 释放内部最大反向波动 / 释放净幅度 | 区分普通与复杂释放，阈值 `TBD` |

### 5.2 回撤与时间

| 特征 | 建议定义 | 书面基线 |
|---|---|---|
| `accumulation_retracement_ratio` | 积累最深回撤 / 主要释放幅度 | 释放加积累家族不超过 `1/2`，最好在 `1/3` 内 |
| `formation_duration_bars` | `formation_start` 至 `ready_time` | 结构形成时间 |
| `duration_ratio` | `formation_duration_bars / release_duration_bars` | 矩形、三角、旗形和头肩结构基线大于 `2` |
| `detection_delay_bars` | `ready_time - 最后必要枢轴 pivot_time` | 评价因果确认延迟 |

### 5.3 枢轴与内部结构

| 特征 | 建议定义 | 用途 |
|---|---|---|
| `pivot_count` | 形成区已确认高低枢轴数量 | 检查初、中、末期完整性 |
| `pivot_alternation_rate` | 高低枢轴交替比例 | 排除同侧噪音枢轴 |
| `touch_count_upper/lower` | 对上下边界的有效触及数 | 衡量结构稳定性 |
| `touch_residual_atr` | 触及点到拟合边线距离 / ATR | 允许小幅刺破但保持尺度一致 |
| `spacing_mean_bars` | 相邻关键点平均间隔 | 内部节奏 |
| `spacing_cv` | 相邻间隔标准差 / 平均值 | 将“接近 1:1”转换为均匀度，阈值 `TBD` |
| `structure_completeness` | 初、中、末期必要关键点是否齐全 | 输出布尔项和连续评分 |

### 5.4 边线与几何

| 特征 | 建议定义 | 用途 |
|---|---|---|
| `upper_slope_norm` | 高点边线斜率 / ATR | 上边界方向 |
| `lower_slope_norm` | 低点边线斜率 / ATR | 下边界方向 |
| `upper_fit_score/lower_fit_score` | 稳健回归拟合质量 | 排除边线不稳定结构 |
| `parallelism_error` | `abs(upper_slope_norm - lower_slope_norm)` | 矩形、旗形、通道 |
| `width_start_atr` | 形成初期上下边界宽度 / ATR | 结构初始宽度 |
| `width_ready_atr` | `ready_time` 上下边界宽度 / ATR | 结构成熟宽度 |
| `width_ratio` | `width_ready_atr / width_start_atr` | 三角形收敛程度 |
| `apex_distance_bars` | 两边线交点距 `ready_time` 的 K 线数 | 排除已经交叉或交点过远的伪三角，阈值 `TBD` |
| `neckline_slope_norm` | 颈线归一化斜率 | 头肩与 M/W |
| `symmetry_price_error` | 对称关键点价格差 / ATR | 肩部、双顶底价格对称性 |
| `symmetry_time_error` | 对称关键点时间差的相对误差 | 结构时间对称性 |

### 5.5 特征分层

| 层级 | 内容 | 是否进入第一版识别器 |
|---|---|---|
| 结构识别 | 释放、回撤、时间、枢轴、边线、颈线、对称性 | 是 |
| 质量评分 | 释放复杂度、积累复杂度、边线稳定性、刺破程度 | 是，先输出评分不做硬门槛 |
| 环境增强 | 前期高低点、关键位置、边线共振、多周期共振 | 后续加入 |

| 交易结果 | 目标位、盈利倍数、加仓结果、后续是否延续 | 否，只用于策略评价 |
| 主观熟悉与风控 | 熟悉度、仓位、成本、风险预算 | 否，不属于图形识别 |

## 7. 识别流程的统一解释

书中 4.14 的关键价值是：交易机会不是一次性分类，而是关键点不断确认后的动态演化。

向上释放后的示意分支：

```text
P1 -> P2 -> P3
  P3 约等于 P1：继续观察，可能形成上矩或上三
  P3 低于 P1：等待 P4
    P4 >= P2：偏向上三
    P4 < P2 且总回撤 < 1/2：偏向上旗
    P4 < P2 且总回撤 > 1/2，后续触及点增多：可能演化为下降通道
  P3 略高于 P1：可能演化为 M 头
  P3 明显高于 P1：等待 P4/P5，可能演化为上升通道或头肩顶
```

向下释放使用镜像逻辑。第一版实现必须保留 `FORMING` 状态，不能在 P2 或 P3 出现后立即强行归类。

## 8. 待确认问题

1. 书中图面角度的坐标比例未固定，算法统一改用 ATR 归一化斜率；具体阈值需从案例反推。
2. 上三、下三的水平边界与严格收敛边界需要结合标准图进一步细分，不能只依赖单一斜率符号。
