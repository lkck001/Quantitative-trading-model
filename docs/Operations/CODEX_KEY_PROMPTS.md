# Codex 关键提示句

> 用途：保存可直接复制给 Codex 的关键提示句，帮助新 Session 快速恢复项目上下文或明确任务边界。
> 本文件不是项目状态来源；当前事实始终以 `SESSION_LOG.md` 为准，长期规则以 `AGENTS.md` 为准。

## 新 Session：恢复后直接执行

> 请先读取根目录 `AGENTS.md` 和 `SESSION_LOG.md`。本次任务是：……；只做：……；不做：……；验收标准：……。确认任务边界后开始执行，不要扩展范围，不要启动子代理。

## 中断后：只检查现场

> 请读取 `AGENTS.md` 和 `SESSION_LOG.md`，然后检查工作树是否存在未完成修改。只汇报当前文件状态、已完成事项、未完成事项和风险，不要继续修改。

> 请停止继续开发，检查当前状态并更新 `SESSION_LOG.md`。只记录当前目标、正式版本、数据基线、已完成事项、未完成事项、风险、验证结果和下一步，不写详细过程，不修改任务之外的文件。
